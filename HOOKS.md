# Hooks Inventory — Smooth Restaurant

Source of truth generated by grepping `src/` (plus the plugin entrypoint) for
`apply_filters`, `do_action`, `add_filter`, and `add_action`.
Naming convention: hooks and filters use the plugin-slug prefix in underscore
style (`smooth_restaurant_menu_saved`), never dotted names.
`do_action()` fires through `DomainEvents::dispatch()`; the only `add_filter`
call maps the menu capability (see subscriptions).
